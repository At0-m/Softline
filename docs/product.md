# Продукт · поиск и допродажа Softline Store

**Покупатель** ищет ПО и оборудование по названию, артикулу, сленгу или задаче. **Менеджер каталога** разбирает промахи по запросам и товарным карточкам. По оценке партнёра до 40% поисков пусты или нерелевантны. Эта оценка из брифа не служит baseline прототипа.

## Данные и проверяемые примеры

[Папка партнёра](https://drive.google.com/drive/folders/1KPh2iP3na1fdNlsYYErohSRvR7GD_Eua) содержит Mindbox.yml.gz.xml (278,5 МБ), XLSX с ожидаемой первой карточкой или категорией и презентацию. В PDF указаны около 500 поисков в день и около 200 тыс. наименований товарной матрицы. Фактическое число записей, формат сжатия и поля проверяет Middle. Витрина — [Store.softline.ru](https://store.softline.ru/). Для совместимости используйте официальные страницы вендоров.

| Запрос | Ожидаемое назначение из просмотренных примеров XLSX |
|---|---|
| 365 | Microsoft 365 для семьи |
| мтс | Страница направления /webinar/ |
| кибер бэкап | Страница Киберпротект с фильтром категории |
| крипто про csp 5.0 | Карточка КриптоПро CSP |

PDF отдельно приводит «сервер» для проверки оборудования и «Astra Linux» для допродажи. Для реального прогона источником точных URL остаётся выданный XLSX.

## Готовность

P0 — поиск из UI по реальному каталогу, точная первая цель, четыре карточки, различение альтернатив и дополнений, хотя бы одна воспроизводимая рекомендация с вендорским доказательством, аналитика промахов, benchmark и запуск стенда.

P1 — подсказки во время набора, акция с проверяемыми условиями, более широкое покрытие категорий и рекомендаций. Ценовое сравнение требует актуального сопоставимого предложения с той же редакцией, сроком и числом мест. Партнёр приводит его как пример. При дефиците времени выбирайте подтверждённую акцию из данных.

**Аналитика.** Для менеджера важна причина ошибки: неверная категория, отсутствующий алиас, пропуск индекса, неизвестный атрибут, отсутствие прямой позиции или необходимость проверки. Популярность, конверсия и потеря выручки требуют реальных событий соответствующего типа. XLSX позволяет оценивать релевантность. Результаты тестов и трафик стенда показываются раздельно.
