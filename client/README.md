# Клиент поиска · Junior (J1)

Статус: демо на фикстуре, **не боевая сборка**. Все данные — синтетические,
домены `.invalid` зарезервированы фикстурой (`docs/contract.md`).

## Запуск

```
python3 client/dev_server.py
```

Открой http://localhost:5173/ (порт — через `PORT`).

Стек: статические HTML/JS/CSS без зависимостей; сервер-заглушка — Python 3
стандартной библиотеки (Node.js в окружении проекта отсутствует).

## Состав

| Файл | Роль |
|---|---|
| `index.html` | строка поиска, демо-примеры, область состояний |
| `api-config.js` | **единственная точка замены источника данных** (`SEARCH_API_BASE`) |
| `api.js` | транспорт `POST /search` (клиент не знает про фикстуры) |
| `cards.js` | компоненты карточек/секций, работают только с полями контракта v1 |
| `app.js` | состояния: загрузка, результат, нет прямого совпадения, сбой; гард устаревших ответов |
| `styles.css` | оформление |
| `dev_server.py` | заглушка `/search`: раздаёт договорные примеры из `fixtures/` |

## Подключение реального POST /search

1. В `client/api-config.js` задать `SEARCH_API_BASE: 'https://<host>'`.
2. Компоненты карточек и состояний не меняются — они зависят только от схемы
   ответа контракта, а не от источника.
3. Заглушку и демо-чипы из `index.html` удалить перед демостендом.

## Демо-запросы (маршрутизация заглушки)

| Запрос | Состояние | Файл фикстуры |
|---|---|---|
| `сервер` (и прочее) | основная выдача, 4 карточки | `fixtures/search-response.json` (не изменён) |
| `мало` | shortfall, реальное число карточек | `fixtures/ui-cases/shortfall.json` |
| `нет совпадений` | нет прямых совпадений, альтернативы | `fixtures/ui-cases/no-direct.json` |
| `дополнение` | complement с evidence + альтернатива | `fixtures/ui-cases/complement.json` |
| `ошибка сервера` | HTTP 500 → экран технического сбоя | — |

Тестовые примеры договорены с контрактом и помечены в
`fixtures/ui-cases/README.md`.
