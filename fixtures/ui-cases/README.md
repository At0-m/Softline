# UI-фикстуры Junior · договорные тестовые примеры

Маркировка: все файлы каталога — **fixture-only**, данные синтетические, домены `.invalid`
зарезервированы фикстурой. Эти примеры не входят в демонстрационный каталог и не
подмешиваются к реальному фиду. Полный фид партнёра получается по инструкции из
`docs/product.md` и не хранится в репозитории.

Согласованы с контрактом v1 (`docs/contract.md`). Каждый файл — тело ответа `POST /search`.

| Файл | Сценарий | Что проверяет |
|---|---|---|
| `shortfall.json` | Запрос «мало» | shortfall=true, реальное число карточек (2), reason |
| `no-direct.json` | Запрос «нет совпадений» | Успешный ответ с нулём прямых совпадений, target=null, пометка и альтернативы |
| `complement.json` | Запрос «дополнение» | Дополнение с base_id и evidence (source_url, checked_at, claim), альтернатива с отличием |

Основной пример остаётся в `fixtures/search-response.json` (не изменялся).
