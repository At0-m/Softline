# Запуск команды · Softline Store

Репозиторный пакет для четырёх сессий разработки. Результат спринта — стенд, где запрос возвращает товар или целевую категорию, четыре реальные карточки и обоснованную допродажу. В комплекте только спецификации, договорённости и стартовые задания.

## Быстрый старт оператора

1. Распакуй пакет в отдельную папку. Перенеси документы в корень проекта с сохранением структуры. Если в репозитории уже есть AGENTS.md или CLAUDE.md, объедини инструкции и сохрани действующие правила. 
2. Дай четырём сессиям один исходный commit, доступ к спецификациям и путь к материалам партнёра. Выбери настроенные у тебя GLM для Senior, Middle, Junior и Sol для Reviewer. Имена провайдеров и model ID зависят от твоего раннера. Ключи для пользовательского поискового агента задаются отдельно.
3. Открой таблицу ниже и отправь каждой сессии её сообщение. Используй существующий координатор, если он уже запускает работников. При отдельных сессиях передавай их короткие handoff-сообщения Senior. Запуск новой четвёрки поверх уже работающих сессий не нужен.
4. Первая общая проверка — запрос «сервер» проходит через UI, API и реальный индекс. Вторая — запрос «антивирус для сервера» меняет категорию. Лишь после этого расходуй резерв на подсказки и акции.

| Кому | Сообщение для копирования |
|---|---|
| Senior · GLM | Ты Senior и интегратор. Прочитай AGENTS.md, team/senior.md, docs/contract.md. Возьми S1, зафиксируй пути модулей и предоставь потребителям один пример ответа. Веди docs/board.md. Интегрируй товарный поиск, допродажу, стенд и сдачу. Запроси у команды evidence по каждому handoff. Начинай с рабочего baseline. |
| Middle · GLM | Ты владелец данных и retrieval. Прочитай AGENTS.md, team/middle.md, docs/contract.md. Начни M1 с профиля реального фида и проверки целевых URL из XLSX. Дай Senior первые реальные карточки, команды сборки индекса и вызова поиска. Затем сравни варианты retrieval на одном снимке. |
| Junior · GLM | Ты владелец интерфейса и клиентской аналитики. Прочитай AGENTS.md, team/junior.md, docs/contract.md. Начни J1 на контрактном примере, сделай состояния прямой выдачи, целевой подборки и нехватки карточек. Подключи реальный API и покажи сквозной переход в карточку. |
| Reviewer · Sol | Ты независимый Reviewer. Прочитай AGENTS.md, team/reviewer.md, docs/acceptance.md. Начни R1 сразу. Зафиксируй контрольные запросы и правила оценки до тюнинга. По мере интеграции проверяй конкретный commit и snapshot. Дай Senior воспроизводимые дефекты и release verdict. |

**Если работа уже идёт:** каждая сессия сверяет свою задачу с фактическим состоянием репозитория и переиспользует готовое. Senior выбирает ближайший непройденный контрольный этап.
